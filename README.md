# NammaWork AI

**Local skills. Collective opportunities.**

A proposed multilingual, voice-first employment platform connecting skilled and daily-wage workers with local employers through intelligent workforce coordination.

## Problem Statement

Workers face language barriers, fragmented employment networks and limited access to digital hiring platforms. Employers struggle to coordinate multiple skilled workers while managing availability, scheduling and budgets.

## Proposed Solution

NammaWork AI enables workers to discover local employment opportunities and employers to assemble multi-skilled teams through a single natural-language request.

## Key Features

- Multilingual voice-based worker registration
- AI-generated structured skill profiles
- Hyperlocal job discovery
- Intelligent multi-skilled workforce assembly
- Availability and scheduling management
- Budget-aware worker recommendations
- Mutual confirmation between workers and employers
- Manual worker selection and replacement recommendations

## Proposed Tech Stack

| Technology | Purpose |
|---|---|
| Amazon Bedrock | AI reasoning and request interpretation |
| ElevenLabs | Voice interaction |
| Model Context Protocol (MCP) | AI tool integration |
| Next.js and Tailwind CSS | Frontend |
| FastAPI | Backend |
| Supabase | Database and authentication |
| Google OR-Tools | Workforce optimization |
| OpenStreetMap | Location-based matching |
